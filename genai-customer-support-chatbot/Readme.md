# North Star Support Bot

## Overview

North Star Support Bot is an AI-powered customer support chatbot built using Botpress. It helps customers quickly find answers related to orders, shipping, returns, product recommendations, and live agent support.

## Features

* Order tracking
* Returns and exchanges information
* Shipping information
* Product recommendations
* Live agent support option
* Friendly and easy-to-use chatbot interface

## Technologies Used

* Botpress
* AI Assistant
* Knowledge Base
* GitHub

## Project Structure

* `README.md` – Project documentation
* `screenshots/` – Chatbot screenshots
* `demo-video/` – Project demo video
* `documentation/` – Additional project documents

## How to Use

1. Open the chatbot.
2. Start a conversation.
3. Ask questions about:

   * Order tracking
   * Returns
   * Shipping
   * Products
   * Live agent support
